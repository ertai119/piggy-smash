# 망치로 저금통 부수기 — 설계 문서

- 작성일: 2026-10-17
- 상태: 사용자 검토 대기 (빌더 검토 반영 완료)
- 시안: `mockups/visual-style.html`(그림체, C 선택), `mockups/screens-flow.html`(화면 흐름, 승인)
- 표기: **[사용자]** = 사용자가 정한 것, **[제안]** = 설계자가 정한 것(사용자가 반대하지 않았지만 따로 확인받지는 않음)

## 1. 무엇을, 왜

안드로이드 폰에서 혼자 즐기는 터치 게임. 화면을 돌아다니는 저금통을 망치로 내리쳐 깨고, 쏟아진 동전으로 망치를 강화해 점점 어려워지는 스테이지를 뚫는다. **[사용자]**

핵심 재미는 두 가지다.
1. **손맛**: 때리고 깨질 때의 소리, 이펙트, 흔들림.
2. **성장**: 동전을 모아 강해져서, 못 깨던 스테이지를 결국 깨는 것.

## 2. 목표 / 비목표 / 실패 조건

**목표**
- 터치 한 번에 망치가 내려치고, 맞은 저금통이 반응하고, 깨지면 동전이 쏟아지는 경험이 매끄러울 것.
- 스테이지가 끝없이 이어지며 점점 어려워질 것. **[사용자]**
- 동전으로 망치 스킬을 강화하는 성장 루프. **[사용자]**

**비목표**
- 앱스토어 배포, 다른 사람과 공유, 계정, 랭킹, 광고, 결제.
- 아이폰·데스크톱 최적화. 단, 데스크톱 크롬에서 마우스 클릭으로 실행되면 개발·확인에 편하다.

**실패 조건 (기술적으로 돌아가도 실패)** **[사용자]**
- **타격감이 약하다.** 효과음, 타격 이펙트가 밋밋하다.
- **저금통이 너무 적다.** 화면이 휑하다. 첫 스테이지부터 화면이 북적여야 한다.

## 3. 제약

- 플랫폼: 안드로이드 크롬에서 실행되는 **웹 게임**. "홈 화면에 추가"로 설치하면 주소창 없이 전체 화면, 오프라인 실행(PWA). **[사용자 승인]**
- 게임 엔진: **Phaser**. **[사용자 승인]**
- 배포: **GitHub Pages.** 사용자 GitHub 계정을 쓴다. **[사용자]** 무료 요금제라 저장소와 게임 주소는 공개되지만, 주소를 따로 알리지 않는다. 서버나 백엔드는 없다.
- 기기: **갤럭시 Z 폴드8**. **[사용자]** 고성능 기기라 성능 여유는 크지만, 화면이 두 개다.
  - 접은 상태(가늘고 긴 커버 화면)와 펼친 상태(정사각형에 가까운 큰 화면) **둘 다에서 플레이**할 수 있어야 한다. 게임 중에 접거나 펼쳐도 화면이 깨지지 않고 새 크기에 맞춰진다. **[제안]**
  - 기본은 **세로 모드**. 화면 비율이 달라지면 HUD는 위쪽에 고정하고, 저금통이 돌아다니는 영역이 화면 크기만큼 늘어나거나 줄어든다. 펼친 화면에서 저금통이 너무 작아 보이지 않게 크기를 화면에 맞춰 조정한다. **[제안]**
- 저장: 진행 상황(현재 스테이지, 동전, 스킬 레벨, 음소거 여부)을 폰 브라우저 저장소에 저장. 앱을 닫았다 열어도 이어서 한다. **[제안]**

## 4. 게임 규칙

### 4.1 한 판(스테이지)

**[사용자]**
- 스테이지가 시작되면 저금통 여러 개가 화면을 돌아다닌다.
- 화면을 터치하면 그 자리에 망치가 내려친다.
- 저금통에는 체력이 있다. 체력이 0이 되면 부서지며 동전이 나온다.
- **제한 시간 안에 그 스테이지의 저금통을 모두 깨면 클리어, 못 깨면 실패.**
- 다음 스테이지로 갈수록 **저금통 수가 많아지고 체력이 높아진다.** 끝없이 이어진다.

**[제안]**
- 저금통은 스테이지 시작 시 전부 등장하지 않고, 화면에 일정 수가 떠 있도록 나눠서 계속 나타난다. 화면 동시 등장 수는 첫 스테이지부터 화면이 북적이는 수준(예: 8개 안팎)으로 시작한다. 정확한 수와 등장 간격은 플레이해보며 맞춘다.
- 저금통은 화면 안을 걸어다니듯 이동하고, 벽에 닿으면 방향을 바꾼다. 스테이지가 오르면 조금씩 빨라질 수 있다.
- 동전은 깨진 자리에서 튀어나온 뒤 **자동으로 동전 카운터로 날아가 합산**된다. 동전을 따로 주우러 다니는 조작은 없다(타격 흐름을 끊지 않기 위해).
- **실패해도 그 판에서 얻은 동전은 유지**된다. 실패하면 같은 스테이지에 재도전한다.
- 이전 스테이지로 돌아가는 기능(스테이지 선택)은 없다. 진행은 클리어하면 다음, 실패하면 같은 스테이지뿐이다. **[제안]**
- 스테이지 난이도 수치(저금통 수·체력·제한 시간의 증가 곡선)는 빌더가 정하되, 아래 원칙을 지킨다.
  - 강화를 전혀 안 하면 몇 스테이지 안에 막힌다.
  - 막혔을 때 실패를 몇 번 반복해 모은 동전으로 강화하면 뚫을 수 있다.
  - 수치는 한 파일에 모아 두어 쉽게 조정할 수 있게 한다.

### 4.2 저금통 종류

**[사용자]**
- **일반 저금통**: 기본.
- **금 저금통**: 체력이 높고 동전을 많이 준다.

**[제안]**
- 금 저금통은 드물게 섞여 나온다. 더 크고 반짝여서 한눈에 구분된다(시안 참고).
- 저금통 종류를 나중에 더 추가하기 쉬운 구조로 만든다. 단, 지금 만드는 건 이 두 종류뿐이다.

### 4.3 망치 강화

**[사용자]** 동전으로 아래 스킬을 강화한다.

| 스킬 | 효과 | 처음 상태 **[제안]** |
|---|---|---|
| 파워 | 한 번 칠 때 깎는 체력 증가 | 열림 |
| 연타 속도 | 연달아 내려칠 수 있는 속도 증가 (망치 모션도 빨라짐) | 열림 |
| 범위 공격 | 내려친 자리 주변 저금통도 함께 피해 | 잠김 → 동전으로 해금 |
| 크리티컬 | 확률적으로 큰 피해 | 잠김 → 동전으로 해금 |
| 연쇄 번개 | 맞은 저금통에서 근처 저금통으로 번개가 튀어 피해 | 잠김 → 동전으로 해금 (가장 비쌈) |

**[제안]**
- 레벨제. 레벨이 오를수록 효과가 커지고 비용이 비싸진다. 레벨 상한은 두지 않거나 넉넉히 둔다.
- 강화는 스테이지 사이의 강화 화면에서만 한다(플레이 중에는 하지 않는다).
- 연타 속도는 "터치 사이 최소 간격"으로 구현한다. 손가락을 대고 있으면 자동 연타가 되지는 않는다(터치할 때마다 한 번).

## 5. 화면

시안 `mockups/screens-flow.html` 참고. **[사용자 승인]**

1. **플레이**: 위쪽에 스테이지 번호, 남은 시간, 보유 동전, 남은 저금통 진행 바와 "남은 저금통 N / 전체". 저금통마다 머리 위에 체력 바.
2. **결과**: 클리어/실패 표시, 이번 판에서 얻은 동전, 깬 금 저금통 수, 최고 콤보. **최고 콤보는 기록용 숫자일 뿐 보상이나 배율은 없다.** 콤보는 저금통을 맞힐 때마다 1씩 오르고, 1.5초 동안 아무것도 맞히지 못하면 0으로 돌아간다. **[제안]** 버튼은 "강화하러 가기", "다음 스테이지"(실패 시 "다시 도전").
3. **강화**: 스킬마다 현재 레벨, 다음 레벨 효과(전→후), 비용 버튼. 잠긴 스킬은 해금 비용 표시. 동전이 부족하면 버튼이 비활성. 아래에 스테이지 시작 버튼.

**[제안]**
- 게임을 처음 열면 짧은 시작 화면(제목 + "시작" 버튼)을 거친다. 이 첫 터치는 브라우저 정책상 소리를 켜는 데에도 필요하다.
- 음소거 버튼을 플레이 화면 구석에 둔다.
- 플레이 중 앱을 벗어나면(홈 버튼 등) 일시정지되고, 돌아오면 이어서 한다.

## 6. 그림체와 타격감

**그림체: 시안 C "선명한 캐주얼"** **[사용자]** — 굵은 검은 테두리, 진한 색, 파란 그라데이션 배경, 큼직한 타격 효과. 저금통·망치·동전 모양은 시안을 따른다.

**타격감** — 사용자가 짚은 핵심은 **깨지는 효과음**과 **망치가 치는 타격 이펙트**다. **[사용자]**

**[제안]** 구체적으로:
- **망치 모션**: 터치하면 망치가 들렸다가 빠르게 내려꽂힌다. 연타 속도 레벨에 맞춰 빨라진다.
- **맞을 때**: 내려친 자리에 노란 충격 별이 터지고, 맞은 저금통이 순간 하얗게 번쩍이며 찌그러졌다 돌아온다. 피해 숫자가 튀어 오른다. 크리티컬은 숫자가 더 크고 다른 색이다.
- **깨질 때**: 저금통이 조각으로 흩어지고 동전이 사방으로 튄다. 금 저금통은 동전이 훨씬 많이 쏟아진다.
- **화면 흔들림 + 진동**: 깨질 때와 크리티컬일 때 화면이 살짝 흔들리고 폰이 짧게 진동한다.
- **번개**: 저금통 사이를 지그재그 번개 줄기가 잇는다.
- **효과음**: 때릴 때 "깡", 깨질 때 도자기 깨지는 소리, 동전 "짤랑", 크리티컬과 번개는 따로. 무료 라이선스 효과음 또는 코드로 합성한 소리 중 빌더가 고른다.
- 저금통이 많이 몰려도 폰에서 끊기지 않아야 한다(아래 성공 기준).

## 7. 성공 기준

1. 안드로이드 크롬에서 "홈 화면에 추가" 후 아이콘으로 전체 화면 실행되고, 비행기 모드에서도 실행된다.
2. 터치에서 망치가 내려치기까지 체감 지연이 없다.
3. 첫 스테이지부터 화면에 저금통이 북적인다.
4. 저금통이 많이 몰리고 연쇄 번개·동전 이펙트가 겹쳐도 사용자 폰에서 끊김 없이 부드럽다.
5. 앱을 닫았다 열어도 스테이지, 동전, 스킬 레벨이 유지된다.
6. 강화 없이 몇 스테이지 만에 막히고, 강화하면 다시 뚫린다.

- 그림을 코드로 그릴지 이미지 파일로 만들지. 단 시안 C의 모양을 따른다.
- 효과음 출처(무료 라이선스 소리 또는 합성).
- 프로젝트 구조, 빌드 도구, 테스트 방식.
- GitHub Pages 배포 절차. 저장소를 만들고 올리는 단계는 사용자와 함께 진행한다.
